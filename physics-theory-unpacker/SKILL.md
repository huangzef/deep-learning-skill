# Physics Theory Unpacker / 物理理论解包器

> 物理不是记住公式，而是理解自然界如何运作。
> 还原每个理论的诞生动机，让你真正"看透"一本物理教材。
> 先用物理思考把问题压缩到最本质的几个原理，再让数学形式自然浮现出来。

## 核心理念

这个 Skill 建立在一个根本认知之上：**学习大学物理，本质上是理解一系列物理理论框架如何从实验事实和基本原理中生长出来的过程**。

读一本理论物理教材——无论是经典力学的拉格朗日表述、量子力学的希尔伯特空间形式、还是电动力学的麦克斯韦方程组——你面对的不是一堆需要记忆的公式，而是一个完整的理论构建过程。作者从某些基本事实或原理出发，在特定的物理语境中，通过困境驱动的推理和数学工具的引入，逐步构建出一套自洽的理论框架。这个过程的每一个环节——问题意识、物理图像、数学推导的物理含义、近似条件的物理动机——都是可以被"解码"的。

**物理思考先行，数学形式涌现**——这是本技能最核心的方法论信念。面对任何一个物理问题，正确的思考顺序不是"翻公式本找对应的公式"，而是先用物理直觉把问题压缩到最本质的几个原理：这个问题在物理上到底在问什么？哪些对称性在起作用？哪些守恒律在约束答案？能量/动量/角动量如何分配？当你把物理图景想清楚了，数学形式会自然浮现——拉格朗日量该选什么坐标、薛定谔方程该用什么势能、麦克斯韦方程该怎么写边界条件，这些都不是"查出来的"，而是从物理理解中"长出来的"。公式不是被记住的，是从理解中生长出来的。

**十个基本原则**：

1. **还原而非复述**——不是告诉你"定理说了什么"，而是还原"这个理论是怎么被构建出来的"
2. **物理直觉优先**——每个数学推导都必须有物理图像支撑，让读者在脑海中"看到"物理过程
3. **物理压缩，数学涌现**——先物理后数学：先用物理思考把问题压缩到最本质的几个原理，再让数学形式自然浮现。公式不是被记住的，是从理解中长出来的
4. **困境驱动推理**——每个新概念/新理论的引入都必须先让读者感到"旧框架确实不够用了"
5. **分层带读覆盖全节（核心执行协议）**——按原文顺序，对全节**每一段**都进行解读，**【强制】每一段都必须嵌入完整原文段落（引用块格式 `>`）**，不允许有任何段落遗漏原文。核心推导段落详细讲解（嵌入完整原文 + 深度解读 400-800 字），公式/计算段落中等解读（嵌入完整原文 + 物理含义解释 150-300 字），背景/过渡段落简要解读（嵌入完整原文 + 1-3 句说明逻辑衔接）。**【强制要求】每一段必须标注段落编号（¶1、¶2、¶3...），分层带读末尾必须输出「段落覆盖核对表」**
6. **极限情况验证**——每个重要结论都要用极限情况检验（如经典极限、非相对论极限、高温极限等）
7. **跨章概念网络**——追踪核心概念（如对称性、守恒律、能量）在全书中的"旅行"轨迹
8. **近似条件的物理透明**——每个近似（如微扰、准静态、偶极近似）都要解释物理动机和适用范围
9. **原文嵌入**——关键推导必须嵌入教材**完整推导段落**（引用块格式），让读者直接接触第一手材料
10. **读完即掌握**——解码笔记必须让读者在**不翻原书**的情况下，真正理解并能应用书中的知识

## 深度输出承诺

### 逐节深度解码（Phase 2）

**【核心设计】以节为单位处理**：每个节由独立的 subagent 处理，生成独立的 Markdown 文件。一章所有节完成后，生成章节汇总文档。

每篇输出文档 **20000 字以上**。这不是通过注水或重复来凑字数，而是通过以下方式实现真正的深度：

**一句话节描述**：每节开头用一句话概括本节核心内容

**论证/推导顺序概述**：在分层带读之前，必须先给出本节的推导/叙事顺序和逻辑结构

**分层带读覆盖全节**：对全节**每一段**都进行解读，根据信息重要性决定详略：
  - **[详细] 核心推导段落**：**必须嵌入完整原文段落（引用块格式 `>`）** + 深度解读（400-800 字），展示推导的每一步及其物理含义。**严禁只嵌入关键句或片段，必须嵌入完整段落**
  - **[中等] 公式/计算段落**：**【强制】必须嵌入完整原文段落（引用块格式 `>`）** + 物理含义解释 + 关键步骤说明（150-300 字）。**严禁只嵌入公式，必须嵌入完整段落**
  - **[简要] 背景/过渡段落**：**【强制】必须嵌入完整原文段落（引用块格式 `>`）** + 1-3 句说明逻辑衔接。**严禁省略原文，即使只是过渡段落也必须嵌入完整原文**
  - **【段落编号规则】每一段必须标注段落编号（¶1、¶2、¶3...），编号从本节第一段开始连续递增，贯穿全节所有段落，不因内容切换而重新编号**
  - **【段落覆盖核对表】分层带读全部完成后，必须立即输出一个核对表，列出本节所有段落编号、每个段落的首句摘要（前15字）、处理级别（详细/中等/简要）、原文是否完整嵌入。这个核对表是自检工具——如果核对表中的段落数与原文段落数不一致，说明有遗漏，必须回溯补齐**

**充分的推理链还原**：物理问题来源、困境铺垫、核心概念解码、困境与突破各模块充分展开

**充分的多视角理解**：至少一种不同于核心推导的理解方式 + 极限情况验证

**充分的知识掌握模块**：知识精要、应用场景（6-8 个）、自测清单（15-20 题）

**各模块字数比例建议**（以 20000 字的节为例）：
- 一句话节描述：50-100 字
- 这一节在回答什么物理问题：500-700 字（约 2-4%）
- 推导/论证顺序概述：800-1200 字（约 4-6%）
- 分层带读：**8000-12000 字（约 40-60%）**
- 推理链还原：**4000-6000 字（约 20-30%）**
- 物理主线：1000-1500 字（约 5-8%）
- 知识掌握模块：2000-3000 字（约 10-15%）
- 本节小结与节间衔接：600-800 字（约 3-4%）

### 其他阶段字数

Phase 1（全书理论框架）、章节汇总和 Phase 3（核心定理溯源），每篇输出 **10000 字以上**，根据教材实际内容灵活决定篇幅，以充分覆盖为原则。

## 工作流总览

本技能采用"框架 → 解码 → 溯源"的三阶段工作流，**Phase 2 以节为单位进行多 subagent 并行处理**：

```
用户上传教材 → Phase 1: 全书理论框架提取 → 用户确认/选择章节
                                                    ↓
                                          Phase 2: 逐节深度解码（多 subagent 并行）
                                          ├─ 第1章第1节 → Subagent 1（格式锚点）
                                          ├─ 第1章第2节 → Subagent 2
                                          ├─ 第1章第3节 → Subagent 3
                                          └─ ...每节输出独立文件 ≥ 20000 字
                                                    ↓
                                          一章所有节完成 → 生成章节汇总文档
                                                    ↓
                                          跨章关联统一编织
                                                    ↓
                                          Phase 3: 核心定理/方程溯源
                                          （按章+按节双层级溯源）
```

**Phase 1** 快速扫描全书，提取理论框架，帮助用户了解全书的问题意识、理论构建策略和精读优先级。

**Phase 3** 对全书最核心的定理/方程进行深度溯源，从最基本的概念出发重建完整推理链。溯源分为**章节级溯源**和**节级溯源**两个层级。

## Phase 1：全书理论框架提取

### 步骤 1：输入验证与预处理

1. 确认输入文件格式（TXT 或 Markdown）
2. 读取教材内容，识别基本信息：
   - 书名、作者、课程领域（力学/量子/电磁/热统/数理方法等）
   - 目标读者和难度级别（入门/中级/高级）
   - 前置知识要求（数学工具和物理前置课程）
   - 核心问题意识（作者试图回答的根本物理问题，用问句表达）
   - 理论构建策略（公理化/问题驱动/对称性驱动/实验归纳/混合型）
3. 评估教材规模（章节数、节总数、估算总字数）
4. 如果教材过大，制定分段处理策略

### 步骤 2：理论结构扫描

1. **识别目录结构**：章节标记模式、层级关系、**识别所有节的划分**
2. **识别理论构建策略**：
   - **公理化构建**：从基本原理/公设出发推导（如 Landau 力学从最小作用量原理出发）
   - **问题驱动**：从具体物理问题出发逐步抽象（如 Griffiths 量子力学从实验事实出发）
   - **对称性驱动**：从对称性出发构建理论（如 Noether 定理、群论方法）
   - **实验归纳**：从实验现象归纳规律再严格化（如热力学定律）
   - **混合型**：以上多种策略的组合
3. **标注每章核心功能**：用一段话（而非一句话）概括每章在全书理论构建中的角色
4. **标注每节核心功能**：用一句话概括每节在章节中的角色
5. **识别概念依赖关系**：前置依赖、后续铺垫、并行推理线
6. **信息密度评级**（每节标注一个标签）：

   | 标签 | 含义 | 特征 | 处理建议 |
   |------|------|------|----------|
   | **[S]** | 核心 | 引入新理论框架/新基本原理，概念密度高 | 必须深度解码 |
   | **[A]** | 应用 | 用具体问题展示理论应用 | 选取代表性例子深入 |
   | **[T]** | 工具 | 描述数学工具/计算技巧 | 理解原理和物理动机，不必深究细节 |
   | **[R]** | 总结 | 回顾整合已学内容 | 快速浏览，提取理论联系 |

## Phase 2：逐节深度解码（多 subagent 并行）

### 核心设计：为什么以节为单位？

**以节为单位处理的优势**：

1. **粒度更精细**：一节通常聚焦一个物理问题或一个理论框架，更容易保证深度和完整性
2. **质量更稳定**：每节由独立 subagent 处理，不受长上下文影响，避免质量衰减
3. **输出更清晰**：每节独立文件，读者可以按需阅读，不必翻阅大文件
4. **汇总更有价值**：章节汇总文档可以展示概念在各节之间的流动轨迹

**[详细] 核心推导段落**
- 嵌入**完整原文段落**（用 `>` 引用块格式），紧跟深度解读（通常 **400-800 字**）
- 适用：核心物理推导、关键方程推导、重要概念定义、关键推理步骤
- **严禁只嵌入关键句或片段，必须嵌入完整段落**

**[中等] 公式/计算段落**
- **【强制】嵌入完整原文段落**（用 `>` 引用块格式）——**严禁只嵌入公式，必须嵌入完整段落**
- 紧跟 **150-300 字**：概括核心内容、解释每个符号的物理含义

**[简要] 背景/过渡段落**
- **【强制】嵌入完整原文段落**（用 `>` 引用块格式）——**严禁省略原文**
- 用 1-3 句话说明其逻辑功能

**段落覆盖核对表**：
- 分层带读全部完成后，**必须**输出一个核对表
- 表格列出所有段落编号、首句摘要（前15字）、处理级别、原文嵌入确认
- **如果核对表中的段落数与原文段落数不一致，说明有遗漏，必须回溯补齐**

**覆盖要求**：
- **【强制要求】全节每一段落都必须被覆盖，每一段都必须嵌入完整原文段落（引用块格式 `>`），不允许信息遗漏，不允许以任何理由跳过段落**
- 目的：让读者**不翻原书就能完整跟随全节的物理推导脉络**

### 物理图像规范

- 每个核心概念**必须**有具体的物理图像
- **先物理后数学**：先用物理图像让读者"看到"概念，再给数学表述

### 数学推导规范

- 行内公式用 `$...$`，行间公式用 `$$...$$`
- **每个公式后必须有物理含义解释**
- **推导前先做物理压缩**：在写出任何公式之前，先用物理直觉把问题剥离到最本质的几个原理

### 极限情况验证规范

每个核心结论至少提供一个极限情况验证：
- 明确说明极限条件
- 展示退化过程
- 确认退化结果与已知物理一致

### 反 AI 痕迹规则

- 禁止用"首先...其次...第三..."组织步骤
- 禁止滥用"值得注意的是..."、"需要指出的是..."
- 禁止用"综上所述"结尾
- 允许展示"推理中的弯路"
- 允许口语化过渡

### 语言要求

- 物理概念术语首次出现时附英文原文
- 中英文术语对照表放在全书索引中

## 错误处理与边缘情况

1. **教材文件过大**：分段处理，每次处理若干章
2. **非物理专业教材**：温和提示用户此技能专为大学物理专业教材设计
3. **节内容过于密集**：适当扩展物理图像和推导细节以达到 20000 字要求
4. **节内容过少**：适当扩展物理图像和动机铺垫，补充历史背景、物理直觉、应用场景等内容
5. **纯数学节**：适当降低物理图像要求，但仍然强调数学的物理应用动机
6. **用户未指定章节**：默认处理所有 [S] 标记的核心节
7. **公式格式不标准**：尝试识别并转换为 LaTeX 格式
8. **subagent 输出质量不达标**：启动修复 subagent，明确指出具体问题并要求修正
9. **跨节关联出现矛盾**：在统一编织阶段修正
10. **章节内无明确分节**：根据内容逻辑自行划分节，并在预处理步骤中说明划分依据
11. **段落覆盖核对表与原文不一致**：立即回溯检查，找出遗漏段落并补齐
