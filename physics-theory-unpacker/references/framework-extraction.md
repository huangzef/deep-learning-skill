# 理论框架提取方法论

> Parent skill: physics-theory-unpacker
> 本文档是 Phase 1 的详细方法论参考。

## 框架提取的核心目标

框架提取不是"列目录"，而是**解码全书理论构建结构**。你需要回答三个问题：

1. **全书从什么物理问题出发？**（起点问题）
2. **作者用什么策略构建这套理论？**（理论构建策略）
3. **这套理论最终要描述/解释什么？**（终态目标）

---

## 步骤 1：识别理论构建策略

物理教材通常采用以下理论构建策略之一（或混合）：

| 策略 | 特征 | 典型例子 |
|------|------|----------|
| **公理化构建** | 从基本原理/公设出发，逐步推导 | Landau 力学（从最小作用量原理出发）、Dirac 量子力学 |
| **问题驱动** | 从具体物理问题出发，逐步抽象 | Griffiths 量子力学（从实验事实出发）、Feynman 讲义 |
| **对称性驱动** | 从对称性出发构建理论 | Noether 定理、群论方法、规范场论 |
| **实验归纳** | 从实验现象归纳规律再严格化 | 热力学定律、电磁感应定律 |
| **历史演进** | 按照物理学史的发展顺序 | 很多入门教材采用此策略 |
| **混合型** | 以上多种策略的组合 | 大多数现代教材 |

识别策略后，在框架中标注。这决定了后续解码笔记的写作风格：
- 公理化构建 → 重点关注"为什么选这些公理"、"公理的物理动机"
- 问题驱动 → 重点关注"问题如何引出新概念"
- 对称性驱动 → 重点关注"对称性如何约束理论形式"
- 实验归纳 → 重点关注"从现象到理论的跨越"

## 步骤 2：概念依赖关系分析

### 物理概念的特殊依赖模式

物理概念之间的依赖关系比纯数学更丰富，因为物理概念还涉及**物理直觉**和**近似条件**的传递：

| 依赖类型 | 含义 | 示例 |
|---------|------|------|
| **数学前置** | 需要先掌握某个数学工具 | 偏微分方程 → 薛定谔方程的求解 |
| **物理前置** | 需要先理解某个物理概念 | 经典力学 → 量子力学的经典极限 |
| **直觉前置** | 需要先建立某个物理图像 | 波粒二象性 → 波函数的概率解释 |
| **方法前置** | 需要先掌握某个分析方法 | 微扰论 → 氢原子的精细结构 |

### 依赖图构建

用有向图表示概念依赖关系，识别以下模式：
- **线性链**：Ch.1 → Ch.2 → Ch.3（严格递进，如力学→电磁学→光学）
- **分叉**：Ch.3 同时为 Ch.4 和 Ch.5 做铺垫（如微积分同时用于力学和电磁学）
- **汇合**：Ch.6 和 Ch.7 的结论在 Ch.8 中汇合（如力学和电磁学在相对论中统一）
- **循环引用**：Ch.5 引用了 Ch.8 的结论（标注为"前向引用"，需特别处理）

## 步骤 3：概念递进链识别

### 物理主线 vs 数学支线

物理教材通常有一条"物理主线"和若干"数学支线"：

- **物理主线**：核心物理概念的演进（如"粒子"→"波"→"波函数"→"量子态"）
- **数学支线**：数学工具的引入（如"常微分方程"→"偏微分方程"→"本征值问题"）

框架提取时，要**明确区分主线和支线**，并标注它们在哪些章节交叉。

### 标注格式

```
物理主线：Ch.1[牛顿力学] → Ch.3[拉格朗日力学] → Ch.7[哈密顿力学] → Ch.12[正则变换]
数学支线：Ch.2[变分法] → Ch.5[常微分方程] → Ch.9[偏微分方程]
交叉点：Ch.3（变分法 + 最小作用量原理 → 欧拉-拉格朗日方程）
```

## 步骤 4：信息密度评级

### 物理教材的评级标准（节级）

| 标签 | 含义 | 物理特征 | 处理建议 |
|------|------|---------|----------|
| **[S]** | 核心 | 引入新理论框架/新基本原理/新物理图像 | 必须深度解码，每个概念都要展开 |
| **[A]** | 应用 | 用具体物理问题展示理论应用 | 选取 1-2 个最典型的例子深入分析 |
| **[T]** | 工具 | 描述数学工具/计算技巧/近似方法 | 理解物理动机，不必深究每个细节 |
| **[R]** | 总结 | 回顾整合已学内容，建立跨节联系 | 快速浏览，提取理论联系和统一视角 |

### 评级注意事项

- **以节为单位评级**：同一章的不同节可能有不同的评级
- 同一节可能同时有 [S] 和 [A] 的内容——标注主要类型
- [T] 类节在物理专业中往往很重要（如格林函数方法），不要完全跳过
- [R] 类节可能包含重要的"统一视角"（如从拉格朗日到哈密顿的过渡），值得浏览

---

## 步骤 5：推荐精读路径

### 基于理论构建逻辑的路径

精读路径应该基于**理论构建的逻辑**，而不是简单的章节顺序：

- **必读（理论核心）**：所有 [S] 标记章节中，位于物理主线上的
- **选读（深化理解）**：[S] 标记但不在主线上的章节；[A] 标记中包含重要物理洞见的章节
- **浏览（了解即可）**：[T] 和 [R] 标记的章节

### 特殊情况

- **"门槛章节"**：某些章节虽然信息密度不高，但不理解它就无法理解后续内容。这类章节应升级为"必读"。
- **"高回报章节"**：某些章节篇幅不长但包含深刻的物理洞见（如 Noether 定理的一章）。这类章节应标注为"高回报"。
- **"可延后章节"**：某些章节需要大量数学工具，第一次读时可以跳过，等需要时再回来。这类章节应标注为"可延后"。

## 质量检查清单

- [ ] **起点问题**：是否用问句表达了全书的核心物理问题？
- [ ] **理论构建策略**：是否识别了作者构建理论的策略？
- [ ] **物理主线**：是否清晰地区分了物理主线和数学支线？
- [ ] **依赖关系**：是否标注了每章的物理前置和数学前置？
- [ ] **概念递进链**：主线/支线/交叉是否清晰？
- [ ] **密度评级**：每章是否有准确的 [S]/[A]/[T]/[R] 标签？
- [ ] **精读路径**：推荐路径是否有充分理由？是否标注了门槛/高回报/可延后章节？
- [ ] **可操作性**：用户看到框架后，是否知道从哪里开始自学？
