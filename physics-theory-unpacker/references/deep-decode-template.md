# 深度解码模板与写作规范

> Parent skill: physics-theory-unpacker
> 本文档是 Phase 2 的详细方法论参考。Phase 2 以**节（section）**为基本处理单元，逐节深度解码，而非逐章处理。

## 解码笔记的核心哲学

物理教材的解码笔记不是"知识清单"，而是**理论构建过程的还原**——现在以**节**为粒度逐层展开。你的目标是让读者在脑海中"重新经历"理论的发现过程——从物理问题出发，经历困境，引入新工具，最终自然地得出理论框架。每一节都是一个完整的思维单元，既有自身的问题动机和推理闭环，又与前后的节紧密衔接。

## 模块写作规范

### "这一节在回答什么物理问题？"模块

**目的**：锚定本节在整个理论构建中的位置。

**写法要求**：
- 用一个**引人入胜的物理问题**开头
- 解释为什么这个问题重要——它在全书理论构建中扮演什么角色？
- 标注"全书画线"：地基/枢纽/转折/收束
- 标注"章内画线"：本节在本章中的位置（引入/展开/深化/收束）
- 不要剧透答案，但暗示解决思路

**示例（量子力学·薛定谔方程章节）**：

> 如果说前一节让我们接受了"粒子具有波动性"这个反直觉的事实，那么一个紧迫的问题立刻浮现：**这种"物质波"遵循什么样的运动方程？** 我们知道光波遵循麦克斯韦方程，声波遵循波动方程，但描述电子的"概率波"呢？它不可能简单地遵循经典波动方程——因为它需要同时满足两个看似矛盾的要求：既要像波一样传播和干涉，又要在测量时"坍缩"为确定的粒子位置。
>
> [全书画线]：**地基**——薛定谔方程是整个量子力学的运动方程，地位等同于经典力学中的牛顿第二定律。后续所有内容（氢原子、自旋、微扰论）都建立在这个方程之上。
>
> [章内画线]：**枢纽**——本节是本章从"波粒二象性的定性讨论"转向"量子力学的定量框架"的关键转折。

### "前置知识速查"模块

**目的**：确保读者有足够的起点，不翻原书也能跟上。

**分级标准**：
- 🔴 必须掌握：本节核心推导会直接用到，不理解就无法跟上
- 🟡 了解即可：偶尔出现，不影响主线理解

**示例（电动力学·麦克斯韦方程章节）**：

> ### 🔴 必须掌握的前置知识
>
> **高斯定理（积分形式）**：$\oint \mathbf{E} \cdot d\mathbf{a} = Q_{enc}/\epsilon_0$。物理含义：通过任意闭合曲面的电场通量等于该曲面所包围的总电荷除以 $\epsilon_0$。这是库仑定律的积分表达。
>
> **斯托克斯定理**：$\oint \mathbf{B} \cdot d\mathbf{l} = \int (\nabla \times \mathbf{B}) \cdot d\mathbf{a}$。物理含义：磁场沿闭合回路的线积分等于通过该回路的磁场的旋度的面积分。
>
> ### 🟡 了解即可
> - 矢量恒等式（$\nabla \cdot (\nabla \times \mathbf{F}) = 0$ 等）：推导中会用到，但不需要理解深层含义
> - 连续性方程：$\nabla \cdot \mathbf{J} + \partial \rho / \partial t = 0$，电荷守恒的微分形式

### "推理链还原"模块

这是解码笔记的核心。以下按子模块逐一说明。

#### 子模块 1：物理问题从哪里来？

**目的**：建立学习动机，让读者感到"确实需要这一节"。

**写法要点**：
- 前一节留下了什么未解决的物理问题？
- 实验上发现了什么新现象？
- 旧理论框架在哪里失效了？
- 用类比帮助理解

#### 子模块 2：核心概念解码

**每个概念的六步展开**（不可乱序）：

1. **一句话定义**——用最朴素的语言
2. **物理图像**——用具体物理情境来解释
3. **为什么需要它**——旧框架的什么局限迫使引入
4. **数学表述**——精确的数学定义 + 公式
5. **物理含义**——公式中每个符号的物理意义
6. **概念旅行追踪**——这个概念在后续节/章中如何变形

**关键原则**：先物理后数学。让读者先"看到"物理图像，再理解数学表述。

#### 子模块 3：困境与突破

**这是解码笔记的**核心**。展示理论构建如何一步步推进。

**结构模式**（可能重复多次）：

```
物理困境 → 引入新概念/新方法 → 物理含义 → 新困境 → ...
```

**每个"困境-突破"循环的写法**：

1. **陈述困境**：旧框架能处理什么？不能处理什么？
2. **解释为什么是困境**：如果忽略这个问题会怎样？
3. **引入新工具**：自然地引入新概念，解释物理动机
4. **分析新工具**：这个新概念有什么关键物理性质？
5. **展示解决方案**：用新概念回答当前的物理问题
6. **指出新问题**：引出下一层

#### 子模块 4：物理压缩：从问题到本质

**目的**：在进入核心推导之前，先用物理思考把问题压缩到最本质的几个原理，让数学形式的选择空间被物理约束大幅压缩，直至"几乎唯一"。

**这是"物理压缩，数学涌现"理念的核心实践环节。** 公式不是被记住的，也不是从天上掉下来的——当物理图景足够清晰时，数学形式会自然浮现。

**写法要求**：

1. **物理问题本质**：抛开所有数学表述，用一段朴素的语言描述"这个问题在物理上到底在问什么？"
2. **约束条件的物理来源**：
   - 对称性约束（如空间平移对称性→动量守恒、旋转对称性→角动量守恒）
   - 守恒律约束（如能量守恒、电荷守恒）
   - 边界条件/初始条件的物理含义
3. **物理图景**：用最少的数学符号描述物理图景——哪些量在变化？它们之间有什么关系？最终结果的大致形式应该是什么样的？
4. **为什么数学形式几乎是唯一的**：解释基于以上物理约束，数学表达的选择空间已经被大大压缩。比如——拉格朗日量必须具有某些对称性，所以只能取某些形式；波函数必须满足某些边界条件，所以解的形式被限定在某些函数族中。这不是"猜出来的"，而是物理约束下的必然结果。

**示例（分析力学·拉格朗日方程章节）**：

> 让我们先做物理压缩。抛开所有数学，这个问题在问什么？——**给定一个力学系统的约束和力，如何最自然地写出它的运动方程？**
>
> 物理约束有哪些？首先，牛顿定律在所有惯性系中形式相同（伽利略相对性原理），所以运动方程必须具有某种对称性。其次，能量守恒要求我们对"什么是能量"有清晰的认识。第三，约束力（如轨道的约束力）不做功，但牛顿方程中它们很碍事——我们希望找到一种自然排除约束力的表述方式。
>
> 物理图景：系统从状态 A 演化到状态 B，沿着某条"真正的"路径运动。所有可能的路径中，只有一条是物理上实现的。这条路径有什么特殊之处？
>
> 为什么数学形式几乎是唯一的？——当我们要求：(1) 描述必须自动排除约束力；(2) 描述必须与坐标选择无关；(3) 描述必须自然地编码对称性→守恒律的关系——那么"最小作用量原理"几乎就是唯一的选择。拉格朗日量 $L = T - V$ 不是凭空定义的，而是以上物理约束下的必然结果。

#### 子模块 5：核心推导

**写法要求**：
- 在物理压缩之后，核心推导应该是"水到渠成"的——数学形式已经从物理理解中浮现出来了，这里只是把它严格地写出来
- 叙事性的推导，不是形式化的证明
- 关键推导步骤用引用块标注
- **每个关键步骤后解释物理含义**
- **展示公式如何从物理理解中"长出来"，而不是从天上掉下来**
- 推导完成后，用一句话点明物理结论

**示例**：

> 从 $\hat{H}\psi = E\psi$ 出发，将哈密顿量代入：
>
> $$
> -\frac{\hbar^2}{2m}\frac{d^2\psi}{dx^2} + V(x)\psi = E\psi
> $$
>
> > **物理含义**：这个方程说的是——粒子的总能量（右边）等于动能（左边第一项，与波函数的"弯曲程度"有关）加上势能（左边第二项）。波函数越"弯曲"（二阶导数大），动能就越大。
>
> 对于自由粒子（$V = 0$），方程简化为：
>
> $$
> -\frac{\hbar^2}{2m}\frac{d^2\psi}{dx^2} = E\psi
> $$
>
> 这就是经典的"波函数在空间中均匀振荡"的图像——自由粒子的波函数是平面波。

#### 子模块 6：极限情况验证

**写法要求**：
- 至少一个极限情况
- 明确说明极限条件
- 展示退化过程（关键步骤）
- 确认与已知物理一致

#### 子模块 7：换一个视角

**写法要求**：
- 给出至少一种不同于主推导的理解方式
- 新视角应提供额外洞察
- 验证理论的稳健性

**常见的多角度策略**：

| 视角 A | 视角 B |
|--------|--------|
| 数学推导 | 物理图像/对称性论证 |
| 微观机制 | 宏观表现 |
| 拉格朗日方法 | 哈密顿方法/牛顿方法 |
| 薛定谔绘景 | 海森堡绘景/相互作用绘景 |
| 坐标空间 | 动量空间 |
| 离散能级 | 连续能谱 |

#### 子模块 8：概念联系

**写法要求**：
- 与前面节/章的概念建立联系（至少 2 处跨节/章联系，其中至少 1 处为同章内跨节联系）
- 与本节内部概念建立递进关系
- 如果有跨领域的联系（如量子力学中的对称性与群论），一定要点明
- 特别注意：同一章内相邻节之间的概念衔接是节级处理的核心优势，要充分利用

#### 子模块 9：反思与质疑

**写法要求**：
- 用 `[解码者注]` 格式
- 指出近似条件的物理合理性
- 分析类比的局限性
- 揭示推导中的隐含假设
- 列出尚未理解的问题

**示例**：

> **[解码者注]**
> - 以上推导假设了势能 $V(x)$ 是实函数。如果 $V(x)$ 是复数，哈密顿量不再厄米，概率不再守恒——这在物理上对应什么？对应有粒子产生或湮灭的过程（如放射性衰变），需要量子场论来处理。
> - "波函数的弯曲程度对应动能"这个类比在三维情况下需要修正——$\nabla^2$ 度量的不是简单的"弯曲"，而是拉普拉斯算子。
> - 尚未理解：为什么薛定谔方程是一阶时间导数、二阶空间导数？这个不对称性是否有更深层的原因？

### "知识掌握"模块

#### 知识精要

"如果你只能记住三件事，应该是这三件"——这是整节解码笔记的"压缩包"。

#### 应用场景

将本节的核心理论和推导方法应用到 2-3 个具体物理场景中。不是抽象地说"有广泛应用"，而是给出具体的、可想象的场景。

#### 自测清单

5-8 个问题，覆盖三个层次：
1. **物理直觉**："用你自己的话解释..."（2-3 题）
2. **数学推导**："为什么..."、"如何从...推导..."（2-3 题）
3. **应用能力**："如果...会怎样..."、"计算..."（2-3 题）

## 写作风格细节

### 篇幅要求（硬性标准）

每节解码笔记总篇幅不少于 **20,000 字**。各模块建议字数：

| 模块 | 建议字数 | 说明 |
|------|---------|------|
| 这一节在回答什么物理问题？ | 500-700字 | 充分的问题动机和理论定位 |
| 推导/论证顺序概述 | 800-1200字 | 物理结构图示+物理推进逻辑 |
| 分层带读 | 8000-12000字 | 全节每段原文嵌入+深度解读 |
| 物理问题从哪里来？ | 500-700字 | 充分的困境铺垫和类比引入 |
| 核心概念解码（每个概念） | 800-1200字/概念 | 六步完整展开+物理图像+概念旅行 |
| 困境与突破 | 2000-3000字 | 每个困境-突破循环 500-1000字 |
| 物理压缩：从问题到本质 | 400-800字 | 物理约束分析+数学选择空间的压缩过程 |
| 核心推导 | 1000-4000字 | 完整推导+每步物理含义+公式涌现过程 |
| 极限情况验证 | 400-800字 | 至少一个极限情况+退化过程 |
| 换一个视角 | 500-1200字 | 至少一种替代理解方式 |
| 跨节关联 | 300-500字 | 与本章其他节、其他章节的联系 |
| 反思与质疑 | 300-500字 | 解码者注+近似分析+遗留问题 |
| 知识精要+应用场景+自测清单 | 2000-3000字 | 三件事+6-8个场景+15-20个问题 |
| 本节小结与节间衔接 | 600-800字 | 本节小结+节间衔接+推理链条延续 |

**篇幅不足时的补充策略**：
- 概念解码不够长 → 补充更多物理图像、类比、反例、与经典理论的对比
- 困境铺垫不够长 → 补充更多历史背景、实验事实、旧理论的具体失败案例
- 推导不够长 → 补充更详细的物理含义解释、中间步骤的动机、多种推导方法的比较
- 极限验证不够长 → 补充更多极限情况、更详细的退化过程
- 应用场景不够长 → 补充更多具体物理问题的完整分析过程
- 节间衔接不够长 → 补充与前/后节概念的显式映射关系、指出跨节推理链条的断裂与弥合
- 节末承启不够长 → 补充本节遗留问题的更深入讨论、预告下一节将引入的新工具

### 叙事节奏

- **开头**：用物理问题引入，建立悬念
- **中间**：困境-突破循环，逐步推进理论构建
- **推导前**：放慢节奏，确保读者跟上物理图像
- **推导后**：加速，快速展示极限验证和多角度理解
- **结尾**：呼应开头的物理问题，收束本节
- **节级节奏要点**：每一节都应是一个完整的思维闭环——读者读完一节后应有"理解了一个完整问题"的满足感。同时，节的末尾要自然地引出下一节的核心问题，形成"问题-解决-新问题"的链条，让读者有继续阅读下一节的动力。相邻节之间的过渡不应突兀，而应像同一根推理链条上的两个环节。

### 公式与文字的平衡

- 公式是工具，不是主角——物理图像才是主角
- 每个公式前后都要有文字解释"这个公式在物理上意味着什么"
- 复杂推导用 `aligned` 环境对齐
- 变量首次出现时说明物理含义

### 禁止事项

- 禁止"首先...其次...第三..."
- 禁止"值得注意的是..."、"需要指出的是..."
- 禁止"综上所述"
- 禁止在推导中突然跳步
- 禁止在没有物理动机的情况下引入新概念
- 禁止只有数学推导没有物理含义解释
- 禁止只有结论没有推理过程
- 禁止忽略近似条件的物理动机

### 推荐表达

- "一个自然的问题是..."
- "旧理论能完美处理 X，但面对 Y 时就束手无策了"
- "问题在于，并不是所有...都..."
- "这一步的物理含义是..."
- "让我们检查一下极限情况..."
- "当 [参数] → [极限值] 时，我们的结果退化为..."
- "这个结果太漂亮了——它把...统一了起来"
- "说白了就是..."、"简单来说..."
