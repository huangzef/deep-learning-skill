## 1. 总览：三大解码器

| 技能 | 领域 | 核心理念 | 核心问题 |
|------|------|---------|---------|
| **geometric-math-decoder** | 纯数学（分析/代数/拓扑/几何等） | 本质洞察 + 几何直观 | "这个概念为什么不得不如此定义？" |
| **physics-theory-unpacker** | 大学物理（四大力学/数物方法等） | 物理直觉 + 数学推导 | "这个公式的物理图像是什么？为什么近似可行？" |
| **humanities-book-decoder** | 社会科学（经济/金融/历史/哲学等） | 思想脉络还原 | "作者从什么问题出发？论证如何构建？" |

三者共享**三阶段工作流**（框架提取 → 深度解码 → 核心溯源），但每个阶段的执行方式因学科特性而不同。

## 2. geometric-math-decoder：纯数学教材本质解码器

### 2.1 适用场景

- **教材类型**：数学分析、线性代数、复变函数、拓扑学、微分几何、抽象代数、泛函分析等**纯数学专业课程**
- **输入格式**：TXT 或 Markdown 格式的教材内容
- **触发关键词**："数学分析精读"、"线性代数深度理解"、"拓扑学直觉建立"、"decode pure math" 等

### 2.2 核心理念：双层穿透

本技能建立在一个根本认知之上：**学习纯数学，本质上是理解数学结构为何必然如此展开的过程**。

两个穿透通道必须**同时打开**：

| 通道 | 名称 | 回答的问题 | 典型表达 |
|------|------|-----------|---------|
| **通道一** | 几何直观 | 它"看起来"像什么？ | "想象一个平面上的向量..." |
| **通道二** | 本质分析 | 它为什么**不得不**是这个形式？ | "如果我们换成...，结构就会断裂..." |

### 2.3 本质分析五层穿透

在解码每个核心概念时，按以下五层由浅入深进行穿透：

| 层级 | 名称 | 要回答的问题 |
|------|------|------------|
| **Layer 1** | 几何直观 | 这个概念「看起来」像什么？ |
| **Layer 2** | 困境驱动 | 旧工具在什么情境下失效了？ |
| **Layer 3** | 结构必然性 | 为什么这个定义是唯一自然的选择？ |
| **Layer 4** | 不变量识别 | 这个概念捕捉了什么不变的东西？ |
| **Layer 5** | 对偶/泛性质 | 这个概念的反面是什么？满足什么泛性质？ |

**核心原则**：每解释一个核心概念，都要让读者产生——"原来这个概念只能这样定义，没有别的可能"——的感受。

### 2.4 四种核心追问

对于每个核心数学概念，必须回答以下问题（至少前三个）：

| # | 追问 | 目标 |
|---|------|------|
| 1 | 这个定义为什么必须是这个形式？换一种会怎样？ | 结构必然性 |
| 2 | 这个概念捕捉了什么不变的东西？ | 不变量 |
| 3 | 如果没有这个概念，数学结构在哪个环节会断裂？ | 结构功能 |
| 4 | 这个概念的反面/对偶是什么？ | 对偶性 |
| 5 | 这个概念可以推广到更一般的结构吗？ | 泛化边界 |

### 2.5 不可避免性论证（核心武器）

对于核心定义和定理，必须执行不可避免性论证：

> "为什么必须是这个定义？如果我们试图换一个，会发生什么？"

具体操作：
1. **候选否定**：假设不用这个定义，换用看似合理的替代方案
2. **追踪后果**：展示替代方案在哪些具体数学情境下会失败
3. **收敛到唯一**：展示所有"合理"候选最终都约化成同一个定义
4. **得出结论**：这个定义不是随意的——任何试图刻画该现象的合理尝试，都会收敛到这个形式

### 2.6 适用教材范围

| 课程分类 | 国外经典教材 | 国内经典教材 |
|---------|------------|------------|
| **数学分析** | Spivak《Calculus》、Rudin《PMA》、Abbott《Understanding Analysis》 | 华东师大《数学分析》、伍胜健《数学分析》 |
| **线性代数** | Axler《Linear Algebra Done Right》、Strang《Introduction to LA》 | 丘维声《高等代数》、蓝以中《高等代数》 |
| **复变函数** | Needham《Visual Complex Analysis》、Ahlfors《Complex Analysis》 | 钟玉泉《复变函数论》、龚昇《简明复分析》 |
| **拓扑学** | Munkres《Topology》、Hatcher《Algebraic Topology》 | 熊金城《点集拓扑讲义》、姜伯驹《同调论》 |
| **微分几何** | do Carmo《Differential Geometry》、Tu《An Introduction to Manifolds》 | 陈省身《微分几何》、陈维桓《微分几何》 |
| **抽象代数** | Dummit & Foote《Abstract Algebra》、Artin《Algebra》 | 丘维声《近世代数》、冯克勤《近世代数》 |

### 2.7 输出规格

- **单节解码笔记**：≥ 15,000 字（中文字符）
- **章节汇总文档**：每章所有节解码完成后生成
- **核心定理/定义溯源**：全书最核心的 1-3 个定理/定义进行深度溯源
- 包含：几何直观、本质分析、困境驱动推理链、证明策略分析、反例与边界、跨章概念网络、反思与质疑、自测清单

## 3. physics-theory-unpacker：大学物理教材推理链解码器

### 3.1 适用场景

- **教材类型**：经典力学、量子力学、电动力学、热力学与统计物理、数学物理方法等**大学本科物理专业教材**
- **输入格式**：TXT 或 Markdown 格式的教材内容
- **触发关键词**："深度阅读物理教材"、"精读理论力学"、"帮我读懂量子力学"、"decode physics textbook" 等

### 3.2 核心理念：先物理后数学

物理不是公式堆砌，而是从实验事实和基本原理出发，通过**数学推理**和**物理直觉**的交织，逐步构建出描述自然界的理论框架。

**核心方法论**：

> **先物理后数学**——先用物理思考把问题压缩到最本质的几个原理，再让数学形式自然浮现出来；公式不是被记住的，是从理解中长出来的。

不是复述定理，而是还原：
- 每个物理理论的**诞生动机**
- 每个数学推导的**物理含义**
- 每个近似背后的**物理图像**

### 3.3 与 geometric-math-decoder 的关键区别

| 维度 | geometric-math-decoder | physics-theory-unpacker |
|------|----------------------|----------------------|
| **知识来源** | 公理和定义 → 定理 | 实验事实和基本原理 → 物理规律 |
| **推理驱动** | 结构必然性（数学结构迫使概念如此） | 物理直觉 + 数学验证（先猜后证） |
| **核心问题** | "为什么必须这样定义？" | "这个公式的物理含义是什么？" |
| **近似处理** | 严格精确，不容近似 | 合理近似是核心工具 |
| **验证方式** | 反例和边界条件 | 极限情况验证和实验对照 |

### 3.4 输出内容

解码笔记包含以下核心模块：

- **物理图像构建**：每个数学表达背后的物理场景
- **推理链拆解**：从基本原理到最终结论的完整推理链条
- **跨章关联追踪**：同一物理概念在不同章节的演变和连接
- **极限情况验证**：当某些参数趋近于 0 或无穷时，结果是否符合已知物理
- **反思与质疑**：理论的适用范围和可能的问题
- **概念网络构建**：物理概念之间的逻辑关系图谱

### 3.5 适用教材范围

| 课程 | 典型教材 |
|------|---------|
| **经典力学** | Goldstein《Classical Mechanics》、Landau《力学》 |
| **量子力学** | Griffiths《量子力学概论》、Sakurai《Modern Quantum Mechanics》 |
| **电动力学** | Jackson《Classical Electrodynamics》、Griffiths《电动力学导论》 |
| **热力学与统计物理** | Pathria《Statistical Mechanics》、汪志诚《热力学·统计物理》 |
| **数学物理方法** | Arfken《Mathematical Methods for Physicists》、梁昆淼《数学物理方法》 |

## 4. humanities-book-decoder：社会科学书籍思想脉络解码器

### 4.1 适用场景

- **书籍类型**：经济学、金融学、社会学、政治学、历史学、哲学、心理学等**社会科学与人文领域书籍**
- **输入格式**：TXT 或 Markdown 格式的书籍内容
- **不适用**：小说、诗歌、散文、戏剧等文学作品
- **触发关键词**："深度阅读社科书籍"、"帮我读懂这本书"、"书籍解码"、"思想脉络"等

### 4.2 核心理念：思想脉络还原

学习是从学习资料中进行**解码**的过程。不是复述内容，而是**还原作者的思想生成过程**：

- 作者从**什么问题**出发？
- 作者受到什么**思想影响**？
- 作者如何**构建论证**？
- 作者**为什么这样写**而不是那样写？

读完解码笔记即可掌握全书核心知识（**理解 + 应用 + 批判**），无需翻阅原书。

### 4.3 与两个数学/物理解码器的关键区别

| 维度 | 数学/物理解码器 | humanities-book-decoder |
|------|---------------|----------------------|
| **知识性质** | 逻辑必然性（公理推导） | 思想偶然性（作者选择） |
| **推理方式** | 从前提必然推出结论 | 还原作者在特定历史/社会条件下的思考路径 |
| **核心问题** | "为什么必然如此？" | "作者为什么这么想？他的论证有说服力吗？" |
| **批判方式** | 反例和极限情况 | 逻辑漏洞、假设质疑、替代解释 |
| **多文本处理** | 跨章概念网络 | 思想对话网络（跨文本关联） |

### 4.4 输出内容

解码笔记包含以下核心模块：

- **原文嵌入**：关键段落引用，确保解读有据可循
- **论证逻辑拆解**：还原作者论证的前提、推理和结论
- **跨章关联追踪**：同一主题在不同章节的展开和深化
- **知识精要**：每章的核心知识浓缩（至少三件事）
- **分析框架提取**：作者使用了什么分析框架？可以应用于哪些其他场景？
- **应用场景**：书中的思想在现实世界中的具体应用
- **自测清单**：检验是否真正理解
- **思想对话网络**：本书观点与其他思想家/著作的对话和交锋
- **跨文本关联**：同一作者的不同著作之间、不同作者之间的观点联系

### 4.5 适用书籍范围

| 领域 | 示例书籍 |
|------|---------|
| **经济学** | 曼昆《经济学原理》、萨缪尔森《经济学》、哈耶克《通往奴役之路》 |
| **金融学** | 巴菲特致股东的信、席勒《非理性繁荣》 |

### 5.1 从数学到物理的桥梁

数学是物理的语言。当一个物理概念的解码涉及底层数学结构时，**physics-theory-unpacker 的推理会自动调用 geometric-math-decoder 的解码框架**，确保数学结构的严格性。

**示例**：量子力学中的希尔伯特空间 → physics-theory-unpacker 会调用泛函分析的解码结果，解释内积空间和算子的几何意义。

### 5.2 从物理到工程的延伸

物理理论是工程技术的理论基础。当物理概念的解码涉及到实际应用时，physics-theory-unpacker 可以链接到对应的工程学科解码器。

### 5.3 跨学科思考

在合适的场景下（如科学哲学、经济学中的数学模型），三个解码器可以协同工作：

- **humanities-book-decoder** 还原作者的思想动机和社会背景
- **geometric-math-decoder** 解析其中的数学结构
- **physics-theory-unpacker** 解读物理类比

## 6. 通用工作流：三阶段解码法

三个解码器共享同一套三阶段工作流架构，但每个阶段的执行因学科特性而差异化。

```
用户上传教材/书籍 → Phase 1: 框架提取 → 用户确认/选择章节
                                              ↓
                                    Phase 2: 深度解码（多 subagent 并行）
                                    ├─ Subagent → 章节 1
                                    ├─ Subagent → 章节 3-4
                                    └─ Subagent → 章节 7-8
                                              ↓
                                    章节汇总（每章完成后生成汇总文档）
                                              ↓
                                    跨章关联统一编织
                                              ↓
                                    Phase 3: 核心定理/定义/论点溯源
```

### Phase 1：理论/思想框架提取

快速扫描全书，提取整体框架（10,000 字以上），帮助用户了解全书的：
- **数学版**：几何-结构主线、概念递进链、论证依赖关系
- **物理版**：物理图像主线、公式推导链、实验验证支撑
- **人文版**：思想脉络主线、论证逻辑框架、跨文本对话网络

输出包含：
- 全书完整目录和信息密度评级
- 核心概念/思想的递进链条
- 章节间的依赖关系和汇合点
- 精读优先级建议

### Phase 2：逐章/逐节深度解码

使用多 subagent 并行处理各章节，每个 subagent 独立拥有完整上下文，确保格式、深度、内容一致性。

- **数学版**：每节 ≥ 15,000 字，包含几何直观 + 本质分析
- **物理版**：每节 ≥ 12,000 字，包含物理图像 + 推理链
- **人文版**：每章 ≥ 10,000 字，包含思想脉络 + 论证拆解

### Phase 3：核心定理/定义/论点溯源

对全书最核心的内容进行深度溯源，从最基本的直觉出发重建完整推理链。

- **数学版**：核心 1-3 个定理/定义的本质溯源
- **物理版**：核心 1-3 个方程/原理的物理图像溯源
- **人文版**：核心 1-3 个论点的思想谱系溯源

## 8. 快速开始

### 8.1 使用前提

- 你有一本想要深入学习的教材或书籍（TXT 或 Markdown 格式）
- 你对"被动阅读"感到不满，想要**主动解码**知识

### 8.2 选择正确的解码器

```
纯数学教材（数学分析/线代/拓扑/抽象代数等）
    → 使用 geometric-math-decoder

物理专业教材（四大力学/数物方法等）
    → 使用 physics-theory-unpacker

社会科学书籍（经济/金融/历史/哲学/心理等）
    → 使用 humanities-book-decoder
```

### 8.3 工作流程

1. **准备教材**：将教材内容转换为 TXT 或 Markdown 格式（支持逐章处理）
2. **启动解码**：上传文件并调用对应的解码器技能
3. **等待 Phase 1**：系统自动提取全书框架（约 1-2 分钟）
4. **确认章节**：根据框架选择需要深度解码的章节
5. **等待 Phase 2**：系统并行解码所选章节（每节约 2-3 分钟）
6. **获取输出**：接收结构化深度解码笔记

### 8.4 注意事项

- **大教材处理**：超过 500 页的教材建议分段处理（每次 3-5 章）
- **并行限制**：Phase 2 同时启动的 subagent 不超过 3 个
- **质量保证**：如果对输出不满意，可以要求聚焦特定概念进行补充解码
