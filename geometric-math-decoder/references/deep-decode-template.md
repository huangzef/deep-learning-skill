# 深度解码笔记模板

本模板用于生成纯数学教材的深度解码笔记，适配多 subagent 并行处理工作流。核心理念是用几何直观理解数学，用结构化思维掌握理论。

---

## 多 Subagent 并行处理说明

### 为什么使用多 Subagent？

处理一本书的多个章节时，如果在一个会话中依次处理，随着上下文变长，后面的节会出现**质量衰减**：格式走样、深度缩水、几何直觉变弱、跨章关联断裂。

解决方案：**每个章节由独立的 subagent 处理**，每个 subagent 拥有完整的技能上下文和模板，确保所有节的输出质量一致。

### 处理流程

```
1. 主会话完成 Phase 1（全书理论框架提取）
2. 准备"全局导航包"（所有 subagent 共享）
3. 准备"章节处理包"（每个 subagent 独有）
4. 启动第一章 subagent（格式锚点）
5. 第一章完成后，启动后续章节 subagent（并行，最多 3 个）
6. 所有 subagent 完成后，进行跨章一致性检查
7. 如有不达标，启动修复 subagent
```

### 全局导航包模板

```markdown
# 《书名》全局导航包

## 一、全书基本信息
（书名、作者、课程领域、核心几何问题、理论构建策略）

## 二、全书理论结构
（几何-结构主线、支线、汇合点，各章在理论构建中的角色）

## 三、跨章概念流动图
（5-10 个核心概念的档案卡，标注每个概念在各章各节的出现和演变）
- 概念 A「名称」：Ch.1·Sec1（首次定义）→ Ch.3·Sec2（扩展应用）→ ...
- 概念 B「名称」：...

## 四、论证依赖关系
- Ch.X 依赖 Ch.Y 的概念/定理：具体是什么？
- Ch.X 为 Ch.Z 铺垫：具体铺垫了什么？
```

## 节解码笔记模板（15000字以上）

### 完整模板结构

```markdown
# 第X章·第Y节：节标题

## 这一节在回答什么数学问题？
> 用一个问句概括本节试图回答的核心数学问题
> 以及：这个问题在几何上有什么直观意义？
> [全书画线]：标注本节所在章节在全书理论结构中的位置（地基/枢纽/转折/收束等）

## 节间衔接
> **与前一节的关系**：前一节（第X章·第(Y-1)节）建立了什么？本节在此基础上推进什么？
> **本节的起点**：前一节留下了什么未解决的数学问题或未完成的理论构建？
> **逻辑链条**：前一节的核心结论 → 本节要解决的新问题 → 本节的理论目标

## 前置知识速查
> 🔴 必须掌握：（本节核心推导会用到的前置概念，每个附几何直觉回顾）
> 🟡 了解即可：（偶尔出现，不影响主线理解的前置概念）

**概念旅行追踪**：
```

## 数学原文分层嵌入规范

### 段落编号规则

- 每一段标注段落编号（¶1、¶2、¶3...），从本节第一段开始连续递增
- 编号贯穿全节所有模块，不因模块的切换而重新编号
- 编号格式：`#### ¶N [级别] 描述`

### 分层级别

**[详细] 核心定义/定理陈述段落**
- 嵌入**完整原文段落**（用 `>` 引用块格式）
- 深度解读 400-1000 字
- 揭示定义动机、几何含义、隐含假设

**[中等] 证明关键步骤/例题段落**
- **【强制】嵌入完整原文段落**
- 100-200 字概括功能、几何意义

**[简要] 过渡/说明段落**
- **【强制】嵌入完整原文段落**
- 1-3 句话说明逻辑衔接

### 段落覆盖核对表

分层嵌入全部完成后，必须输出核对表：

```markdown
## 段落覆盖核对表

| 段落编号 | 首句摘要（前15字） | 处理级别 | 原文是否完整嵌入 |
|---------|-------------------|---------|----------------|
| ¶1 | ... | [详细] | ✅ |
| ¶2 | ... | [中等] | ✅ |
| ¶3 | ... | [简要] | ✅ |
| ... | ... | ... | ... |
| ¶N | ... | [...] | ✅ |

**统计**：本节共 N 个段落，全部已覆盖，全部已嵌入完整原文。
```
